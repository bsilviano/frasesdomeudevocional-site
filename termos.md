# Termos de Uso

Última atualização: 23 de outubro de 2026.

O projeto Frases do Meu Devocional é um projeto pessoal que publica frases de fé em vídeos curtos nas redes sociais. Este site apenas descreve o projeto e não oferece cadastro, login nem serviços a visitantes.

## Uso do conteúdo

As frases e os vídeos são publicados para inspiração e podem ser compartilhados com indicação da fonte. As músicas usadas nos vídeos são de autoria do próprio criador do projeto.

## Contas das redes sociais

O aplicativo do projeto usa somente a autorização do próprio dono das contas (YouTube, Instagram e TikTok) para publicar os vídeos do projeto. Nenhum dado de terceiros é acessado.
